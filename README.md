# Lâm Nguyễn — Portfolio

Personal portfolio for [Lâm (Liam) Tùng Đức Nguyễn](https://www.linkedin.com/in/lamndt/), hosted with GitHub Pages at [devfuse.me](https://devfuse.me/).

The site is intentionally dependency-free: semantic HTML, responsive CSS, and a small amount of vanilla JavaScript for language switching, reveal motion, and reading progress.

Typography is self-hosted from the Google Fonts distribution; the applicable SIL Open Font License files live beside the font assets in `assets/fonts/`.

## Local preview

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
