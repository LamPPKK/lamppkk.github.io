# Lâm Nguyễn — Portfolio

Personal portfolio for [Nguyễn Đức Tùng Lâm (Liam)](https://www.linkedin.com/in/lamndt/), hosted with GitHub Pages at [devfuse.me](https://devfuse.me/).

The site is intentionally dependency-free: semantic HTML, responsive CSS, and a small amount of vanilla JavaScript for EN/VI/JP language switching, reveal motion, and reading progress.

The content includes selected open-source work, a 12-engagement project archive, eight core credentials, professional experience, and a downloadable PDF CV.

Typography is self-hosted from the Google Fonts distribution; the applicable SIL Open Font License files live beside the font assets in `assets/fonts/`.

## Local preview

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
